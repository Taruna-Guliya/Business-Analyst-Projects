# Project 2: Zomato Delivery Operations Analytics — Performance & Resource Optimization

Analyzed **delivery operations data** to identify **SLA breaches, delivery delays, operational bottlenecks, and resource allocation issues**.

---

## This Project Contains

### SQL Queries

This contains all the **SQL queries used for data extraction, KPI analysis, SLA tracking, delivery performance analysis, and operational insights**.

### RCA & KPI Framework

This contains the **Root Cause Analysis (RCA)** and **KPI Framework** documents used to identify operational issues and define business performance metrics.

### Power BI Dashboard

This contains the **interactive Power BI dashboard** showing **delivery performance, SLA adherence, city-wise analysis, operational KPIs, trend analysis, and executive-level insights**.

### Dataset

This contains the **fact_orders, dim_city, and dim_delivery_person** tables used for analysis, data modeling, KPI calculation, and dashboard creation.
