# Business Analyst Projects
Portfolio of business analyst work — requirements documentation, data analysis, and dashboards.

## Project 1: SkyLink International Airport — Airline Delay & Resource Optimization
Analyzed 5,900+ flight records to identify delay bottlenecks, gate congestion, and resource allocation issues.

  2. Supported Documents: This contains the BRD and Executive Summary Docs
  3. Cleaned Sheet: This is the excel spreadsheet which contains raw data, cleaned data, all the main tables and dashboards along with KPIs. View this to analyse the      cleaning process, how main table got divided into operational tables. 

**Tools:** Excel, Pivot Tables, Dashboards

**Skills:** Requirements Gathering, KPI definition, Root Cause Analysis, Stakeholder Analysis
